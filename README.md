# 말문 쉐도잉

사람을 만나면 영어가 입에서 잘 안 나오는 문제를 풀려고 만든 **말하기 중심 영어 연습 앱**.
단어 암기나 독해 대신 **쉐도잉 → 문장별 말하기(자동 채점) → 외워서 말하기**를 30초부터 10분 길이까지 단계적으로 올려 간다.

- **휴대폰(주 사용):** https://sirius4lee-dot.github.io/malmun/ — Chrome(아이폰은 Safari)으로 열고 "홈 화면에 추가"
- **PC:** 이 폴더의 `말문 시작.bat` 더블클릭(Edge로 열림) 또는 `index.html`을 Chrome/Edge로 열기
- 저장소: https://github.com/sirius4lee-dot/malmun (공개, main 브랜치 루트를 GitHub Pages로 배포)

## 1. 화면과 기능

### 연습 탭
- 상단: 오늘 연습 시간, 연속 연습 일수, "이어서 하기"(진행 중이거나 아직 마스터하지 않은 첫 스크립트)
- 길이별 단계(30초 · 1분 · 2분 · 3분 · 5분 · 10분)마다 스크립트 카드. 카드에 예상 시간(분당 140단어 기준), 단어 수, 3단계 진행 상태 표시
- 맨 아래 **새 스크립트 추가하기**: 영어 글을 붙여 넣으면 단어 수로 단계 자동 배정, 한국어 번역은 선택(한 줄에 한 문장)

스크립트를 열면 3단계:

| 단계 | 하는 일 | 완료 기준 |
|---|---|---|
| 1. 듣고 따라하기 | 원어민 음성(TTS)이 문장씩 재생. 속도 0.7~1.1×, 반복 1~3회, "따라할 틈"(문장 길이만큼 / 없음 = 겹쳐 말하는 진짜 쉐도잉), 한국어 해석 켜기, 글자 가리고 듣기 | 처음부터 끝까지 1회 재생 |
| 2. 문장별 말하기 | 한 문장씩 듣기·천천히 듣기 → **따라 말하기**(음성 인식 채점). 단어별 색: 초록 정확 / 노랑 비슷 / 빨강 빠짐·틀림. 자동 진행 모드(듣기→말하기→80점 넘으면 다음, 3번까지 재시도). 채점 후 **녹음해서 들어 보기 → 내 목소리 / 원어민 → 내 목소리 이어 듣기** | 모든 문장 80점 이상 |
| 3. 외워서 말하기 | 도움 방식 선택: 아무것도 안 보기 / 첫 글자 힌트 / 한국어만 보기 / 보고 읽기. 끝나면 총점, 시간, 분당 단어 수, 문장별 점수, 틀린 단어 표시, **틀린 문장만 2단계로 모아 연습** | "아무것도 안 보기" 90점 이상 = **마스터** |

- 대본의 **아무 단어나 누르면** 뜻 시트: 한국어 뜻(내장 사전), 영어 사전 풀이·발음기호(dictionaryapi.dev), 발음 듣기, 그 문장과 해석, 네이버·Cambridge 사전 링크, **단어장에 저장(☆)**. 저장한 단어는 대본에 금색 밑줄
- 스크립트마다 **핵심 표현** 칩 — 눌러서 뜻 보기·단어장 저장

### 단어장 탭
- 전체 / 외우는 중 / 외움 필터, 발음 듣기, 외웠어요 표시, 삭제, 내 메모 입력
- **말하기 퀴즈**: 한국어 뜻과 빈칸 예문을 보고 영어로 말하면 정답 판정. 3번 맞히면 자동으로 "외움"

### 기록 탭
- 연속 연습 일수, 총 연습 시간, 직접 말한 시간, 마스터 수
- 최근 20주 하루 연습 시간 달력(5단계 색), 길이별 단계 진행 막대(마스터 / 따라말하기 완료), 최근 채점 30개 표
- **백업 파일 받기 / 불러오기**(JSON) — PC와 휴대폰 기록은 따로 저장되므로 옮길 때 사용

### 설정(⚙)
원어민 목소리 선택, 기본 속도, 목소리 들어 보기(실패 시 오류 코드·영어 목소리 개수 표시), 마이크 테스트, 한국어 해석 보기

### 스크립트 추가하는 법
1. **Claude에게 요청(추천):** `content.js`의 `window.SCRIPTS`에 같은 형식으로 추가 → commit·push. ID는 겹치지 않게(예: `s30d`). 기존 기록은 ID 기준이라 그대로 유지됨
   ```js
   { id: 's30d', level: '30s', title: '...', ko: '한국어 설명',
     lines: [["English sentence.", "한국어 해석"], ...],
     phrases: [["표현", "뜻"], ...] }
   ```
   `level`은 `30s` `1m` `2m` `3m` `5m` `10m` 중 하나. 새 단어의 한국어 뜻은 `GLOSSARY` 문자열에 `단어=뜻|` 형식으로 추가
2. **앱에서 직접:** 연습 탭 맨 아래 "새 스크립트 추가하기". 그 기기에만 저장됨(백업 필요). 글감 추천: VOA Learning English(공공 저작물), TED 대본(개인 학습용)

## 3. 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 앱 전체(화면·스타일·로직). 외부 라이브러리 없음, Google Fonts만 사용 |
| `content.js` | `SCRIPTS`(기본 스크립트), `GLOSSARY`(단어=한국어 뜻 약 300개), `IRREGULAR`(불규칙 동사 → 기본형) |
| `manifest.json`, `icon-192.png`, `icon-512.png` | 홈 화면 앱(PWA) 설정과 아이콘(청록 바탕 마이크) |
| `말문 시작.bat` | PC에서 Edge로 여는 바로가기 (git에는 올리지 않음) |
| `README.md` | 이 문서 |

### index.html 주요 부분
- **저장소** `S` — localStorage 키 `malmun.v1`
  ```
  progress[스크립트ID] = { listened, sent: {문장번호: 최고점}, mem: {none|first|ko|read: 최고점} }
  words[단어] = { word, meaning, def, ex, exKo, src, added, learned, ok(퀴즈 정답 수), note }
  log[] = { t, id, mode(listen|sent|mem-*|quiz), secs, score }   // 최대 4000개
  custom[] = 내가 추가한 스크립트,  settings = { voice, rate, showKo, repeat, gap, hint, recordVoice }
  ```
- **TTS** — `speechSynthesis` 래퍼. 영어 목소리 중 Natural > Online > Google 순으로 자동 선택. `say()`는 실패 시 목소리 지정 없이 1회 재시도, 결과는 `TTS.last {ok, err}`
- **Listener** — Web Speech API 음성 인식(en-US). 말 멈춤(silenceMs)·최대 길이·무발화 시간으로 자동 종료, 끊기면 자동 재시작
- **Recorder** — MediaRecorder 녹음. `recordAlone()`은 AnalyserNode로 소리 크기를 보고 말이 끝나면 자동 종료
- **채점** `grade(lines, spoken)` — `normTokens()`로 정규화 후 `align()`(LCS)로 대본과 맞춤
  - 숫자 ↔ 영어(6:30 ↔ six thirty, 20% ↔ twenty percent), 축약형(I'm ↔ I am), 하이픈·따옴표 무시
  - 정확 1점, 어미만 다름(pick/picked) 0.7점, 빠짐 0점 → 대본 단어 수로 나눠 100점 만점
  - 대본에 없는 말(extra)은 감점 없이 개수만 표시
- **화면** — `render()`가 탭/단계별 HTML을 다시 그림. 클릭은 `document` 하나에서 위임 처리

## 4. 플랫폼에서 알게 된 것 (중요)

| 문제 | 원인 | 해결 |
|---|---|---|
| claude.ai 아티팩트로 못 올림 | 아티팩트는 이 계정에서 마이크 권한이 없어 음성 인식 불가 | GitHub Pages(HTTPS)로 배포 |
| 휴대폰에서 "처음부터 재생" 시 소리 없이 문장이 휙휙 넘어감 | 안드로이드 Chrome은 `cancel()` 직후 `speak()`하면 새 문장도 취소됨 → 즉시 "끝남"으로 처리돼 다음 문장으로 | 말하는 중일 때만 cancel, 실패 감지 시 멈추고 안내(볼륨·브라우저·TTS 엔진) → **사용자 확인: 소리 나옴** |
| 안드로이드 음성 인식 결과 중복 | continuous 모드 버그 | 안드로이드만 continuous=false로 한 문장씩 받고 자동 재시작 |
| 녹음 켜면 채점이 0점(녹음은 잘 됨) | 안드로이드는 마이크를 녹음과 인식이 동시에 못 씀. 같은 트랙을 인식에 넘기는 `start(track)`도 사용자 폰에서 안 됨 | **채점 따로, 녹음 따로**: 채점 후 "녹음해서 들어 보기"로 한 번 더 말해 녹음. 채점 후 따로 녹음이 기본. "채점하면서 동시에 녹음" 체크는 모든 기기에 보임(v1.6, 사용자 재시험용) |
| 삼성 인터넷·카카오톡 인앱 브라우저 | 음성 합성/인식이 안 되거나 불안정 | Chrome(아이폰은 Safari)으로 열도록 안내 |

- 음성 인식은 인터넷 연결 필요, 이어폰 사용 권장(스피커 소리가 마이크로 들어가면 오채점)
- 기록은 브라우저마다 따로 저장(PC ≠ 휴대폰). 사이트 데이터 삭제 시 사라짐 → 백업 파일
